<h2>What I'm building</h2>

**🎙️ [FieldVoice](https://github.com/andrewgomez1992/fieldvoice)** — a hands-free AI voice assistant that turns a spoken site walkthrough into a finished inspection report. Two interchangeable engines: a live speech-to-speech session over WebRTC with OpenAI's realtime model, and a cheaper step-by-step wizard on AWS Polly. The OpenAI key never reaches the phone — the server mints 300-second ephemeral credentials — and every session carries a hard 25-minute cap with live per-token cost estimation. Reports build from JSON templates, so new report types ship without new code.
<br/>`React · Node.js · OpenAI Realtime API · WebRTC · AWS Polly`

**🧭 [Trail](https://github.com/andrewgomez1992/job-tracker)** — a full stack job search command center I built and run my own search out of: a drag-and-drop pipeline, follow-up reminders, resume-to-posting match scoring and a bookmarklet that saves jobs from any site. Layered Express API (routes → controller → service → repository) with SQL migrations, Zod validation and 54 end-to-end tests. The public demo compiles that same backend to run entirely in the browser on SQLite via WebAssembly — no server, no hosting cost.
<br/>[**Live demo →**](https://job-tracker-two-bay.vercel.app/) · `React 19 · Vite · TanStack Query · Express 5 · SQLite · WebAssembly`

**📦 [The Node Forge](https://www.npmjs.com/org/the-node-forge)** — three open-source packages I publish and maintain, each fully typed with Jest coverage, CI on GitHub Actions and Docusaurus docs.
<br/>• [`regex-simplifier`](https://www.npmjs.com/package/@the-node-forge/regex-simplifier) — build, explain and test regular expressions in plain English
<br/>• [`url-shortener`](https://www.npmjs.com/package/@the-node-forge/url-shortener) — pluggable shortlink service with custom aliases and expiry
<br/>• [`loader-kit`](https://www.npmjs.com/package/@the-node-forge/loader-kit) — spinners, progress bars and dot loaders for JS/TS apps

**🕯️ [Vanish Candles](https://vanish-candles.vercel.app)** — a mobile-first e-commerce storefront with a NestJS backend, plus cart and checkout flows on Stripe payments and webhook handling.
<br/>`React · TypeScript · NestJS · Stripe`
